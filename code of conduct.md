# Code of Conduct

## Purpose

This is a personal learning repository for exploring **Node.js**, **Express**, and **React**. While primarily for self-study, this code of conduct outlines the standards I hold myself and any contributors to.

---

## Guiding Principles

### 1. Learning Over Perfection
This repo exists to learn. Messy commits, experimental branches, and half-finished ideas are welcome. Progress matters more than polish.

### 2. Respectful Collaboration
If others contribute (via issues, PRs, or comments), all interactions should be:
- Kind and constructive
- Patient, especially with beginners
- Free from harassment, discrimination, or condescension

### 3. Honest Attribution
- Credit tutorials, articles, or Stack Overflow answers used in code comments or commit messages.
- Do not copy-paste code without understanding it — the goal is learning.

### 4. Clean and Intentional Commits
- Write clear commit messages (e.g., `add basic Express routing` not `stuff`).
- Avoid committing sensitive data such as API keys, `.env` files, or passwords.
- Keep `node_modules/` and build artifacts out of version control.

### 5. Openness to Feedback
- Feedback on code, structure, or approach is welcome and encouraged.
- Critique the code, not the person.

---

## Scope

This code of conduct applies to all activity within this repository — commits, issues, pull requests, and any related discussions.

---

## Reporting Issues

If something feels off or unwelcoming, feel free to open an issue or reach out directly via the contact info on my GitHub profile.

---

## Acknowledgement

By contributing to this repository, you agree to abide by these principles.
